# Versiones de mayor resolución

Estas versiones se han restaurado a partir de las doce ilustraciones pequeñas originales, con la herramienta de edición de imágenes. Se mantiene el fondo blanco opaco del material de origen; las pruebas con transparencia se descartaron por introducir artefactos.

Se han reconstruido los bordes para mejorar la nitidez al ampliarlos. El proceso puede variar detalles pequeños del dibujo. Los archivos originales permanecen sin cambios en la carpeta superior. La versión mejorada del león elimina la marca oscura ajena al animal que aparecía en el borde derecho.

`media.js` apunta a esta carpeta para los ejercicios y a la versión mejorada del perro para la tarjeta del tema. Los elementos se muestran con `object-fit: contain`, sin recortar, y conservan la carga diferida.
