# Acciones habituales

Las doce ilustraciones de `Acciones.rar`, proporcionadas por la autora, se conservan sin modificar sus bytes ni su resolución (145–190 px de ancho). Se muestran a tamaño moderado: ampliar un archivo pequeño no aporta más detalle.

El tema conserva la ruta `rutina` para mantener los enlaces existentes. Sus nombres visibles son «Acciones habituales», «Everyday actions» y «Повседневные действия». Tiene reconocimiento de imágenes, una historia con verbos en presente e imágenes en los huecos, memory con las doce acciones, frases para ordenar y crucigrama. La revisión `acciones-v2` evita heredar la finalización de los ejercicios antiguos.

Para mejorar la nitidez, sustituir los PNG por versiones originales de mayor resolución con los mismos nombres; no ampliar artificialmente estos archivos.

Los recortes de caminar y correr solicitados por la autora se guardan en `recortes/`; las ilustraciones originales de esta carpeta se conservan sin cambios. El memory precarga todas las imágenes antes de permitir el primer giro.
